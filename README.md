# 问渠

> 有源之问，方有清渠之答

问渠是一个面向技术内容创作、检索与智能问答的内容分享平台。平台以「多级缓存 + 检索增强生成（RAG）」为核心：
读路径由本地缓存、Redis 页面缓存与条目缓存分层承载，长文阅读场景提供基于向量检索的流式问答。

## 平台特性

- **分层缓存读路径**：本地缓存 → Redis 页面缓存 → 条目缓存，热点内容自动识别与预热
- **AI 伴读**：长文详情页内基于向量检索的流式问答，逐字输出、随时中止
- **创作发布**：草稿 → 图片直传对象存储 → 正文直传并回执校验 → 补元数据 → 发布
- **内容与社交**：内容流无限滚动、搜索联想与游标分页、关注关系、点赞与收藏
- **双主题设计系统**：天青 × 竹纸配色，亮 / 暗 / 跟随系统三态

## 技术栈

| 层面 | 选型 |
| --- | --- |
| 前端 | React 19 · TypeScript · Vite · TanStack Query · React Router · zustand |
| 后端 | Java 21 · Spring Boot 3 · Spring Security · Spring AI |
| 存储 | MySQL · Redis · Elasticsearch |
| 中间件 | Kafka · Canal · 阿里云 OSS |

## 本地启动

环境准备（数据库、中间件、环境变量）见 [docs/本地环境.md](docs/本地环境.md)。

前端：

```bash
cd wenqu_frontend
npm install
npm run dev
```

前端默认端口 `5173`，`/api` 请求代理到 `http://localhost:8080`。
