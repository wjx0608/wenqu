## 5. 提交规范

采用 Conventional Commits，一次提交只做一件可验证的事：

| 前缀 | 用途 |
| --- | --- |
| `feat(scope)` | 新增功能 |
| `fix(scope)` | 缺陷修复 |
| `refactor(scope)` | 不改变行为的结构调整 |
| `style(scope)` | 样式与格式 |
| `docs` | 文档 |
| `chore` | 构建、依赖、配置 |

提交前自查：`npm run typecheck`、`npm run lint`、`npm run build` 全部通过。
